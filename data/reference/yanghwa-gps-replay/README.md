# 양화대교 북단 GPS 재생 시험 경로

확인일: 2026-11-14. 이 자료는 실제 도로 위치 위에서 Pleos FusedLocation SDK → 앱 구간 감지 → 안내 표시/종료를 시험하기 위한 개발용 좌표다. 승인된 실차 차로 안내 데이터가 아니다.

## 선정 구간과 증거

양화대교 북단 진입로에서 강변북로 난지 방향 본선으로 이어지는 약 808.5 m 경로다. OpenStreetMap의 `oneway=yes` 도로 순서 `333579041 → 333681709 → 333681710 → 524851908 → 206487103`를 연결했다. 각 도로의 마지막 노드와 다음 도로의 첫 노드가 동일한지 수집 스크립트로 검증했다.

- 시작: 위도 37.5485900 / 경도 126.9105767.
- 도로 연결점: OSM node 387154717, 위도 37.5486902 / 경도 126.9060418. 누적 거리 404.566 m.
- 종료: 위도 37.5510415 / 경도 126.9025669. 누적 거리 808.512 m.
- `route.json.points` 순서는 `[경도, 위도]`이며 도로 진행 방향이다.
- 누적 거리는 지구 반경 6,371,000 m의 haversine 선분 길이 합이다. 위도/경도 중심선을 따라 보간하여 재생한다.

서울시설공단 [위치정보검색시스템 428페이지](https://www.sisul.or.kr/open_content/driveway/pis/pisMasList.do?pgno=428)의 W618 항목은 강변북로 난지방향 양화대교 지난 135 m 주변의 양화대교 북단 합류를 설명한다. 이는 구역과 방향의 교차 확인이며 OSM 연결점 좌표를 측량 검증한 자료는 아니다.

## 알림 시험창

`startAlongMeters=224.566`, `endAlongMeters=474.566`은 개발자가 정한 시험 표시 범위다. 연결점 180 m 전부터 70 m 후까지다. 공식 도로 시설 경계, 가속차로 시작/끝, 법적 차로 변경 지점을 뜻하지 않는다. 경로 시작~224.566 m에서 대기, 창 안에서 위치 안내, 통과 뒤 숨김을 검증한다.

## 표현 가능한 것과 한계

표현 가능: 실제 지도상의 진입로와 본선 연결, 지정 위치 구간 접근/통과, 위치 SDK 수신에 따른 표시 여부.

확인하지 못한 것: 현재 차량 차로, 차로 끝의 정확한 위치, 진입 차로 수, 도색/표지, 합류 가능 간격, 지금 차로를 끝까지 유지해도 된다는 판단, 기본 내비 경로와의 일치. 따라서 이 자료만으로 ‘끝까지 가세요’, ‘지금 끼어드세요’, 특정 차로 수를 안내해서는 안 된다. 실차 위치 오차·평행도로·고가 아래 도로 구분도 별도 검증 대상이다.

OSM은 공동 편집 데이터이며 도로 way의 최종 수정 시각과 실제 도로 현황의 확인일은 다르다. 일부 진입로 way는 2017년 버전이고 참조 노드는 더 최근 수정되었을 수 있다. 이번 시험은 현행 차로 구조 검증을 대신하지 않는다.

## 출처·라이선스·재현

`osm-way-*-full.json`은 OpenStreetMap 공식 공개 API의 원문이며 버전과 태그를 보존했다. `route.json`은 해당 노드 좌표를 진행 방향으로 이어 만든 데이터다. 원문 및 파생 JSON SHA-256은 `sha256.json`에 있다.
