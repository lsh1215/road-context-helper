# 망원 합류·진출 데모

합류 뒤 실선 구간과 이후의 짧은 차로 변경 구간을 구분해 왼쪽 진출을 준비하는 화면을 카카오내비 옆에서 비교합니다. 첫 4초는 초행길의 정차 중 도로 유형 시연입니다.

- `comparison.mp4`: 전체 2분 16초
- `highlights.mp4`: 핵심 1분 16초

두 앱에 같은 141개 GPS 입력을 재생했습니다. 초행길 화면은 최신 Pleos 에뮬레이터 앱으로 다시 촬영했고, 카카오내비 화면과 음성은 이전 모바일 녹화 원본을 사용했습니다. 하단 해설 자막은 없습니다. 두 화면의 시간은 대략 맞춘 것이며 반응속도 비교가 아닙니다.

도로 모형은 2026년 6~7월 거리뷰를 참고했습니다. 공사와 차선 변경 가능 거리의 현 상태는 확인되지 않았고, 차량 모형의 좌우 차로 배치는 설명용입니다.
