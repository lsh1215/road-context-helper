# 응봉지하차도 출구 데모

두 진입 차로가 순서대로 끝나는 구조와 각 차로 끝까지 남은 거리를 카카오내비 화면 옆에서 비교합니다. 첫 4초는 초행길의 정차 중 도로 유형 시연입니다.

- `comparison.mp4`: 전체 2분 14초
- `highlights.mp4`: 앞부분을 줄인 2분 4초

두 앱에 같은 128개 GPS 입력을 재생했습니다. 초행길 화면은 최신 Pleos 에뮬레이터 앱으로 다시 촬영했고, 카카오내비 화면과 음성은 이전 모바일 녹화 원본을 사용했습니다. 하단 해설 자막은 없습니다. 두 화면의 시간은 대략 맞춘 것이며 반응속도 비교가 아닙니다.

차로 끝 위치는 거리뷰 관측 범위로 표시한 추정치입니다. 차량 모형의 앞뒤 진행은 Pleos 위치 SDK 입력에 따르고, 좌우 차로 배치는 설명용입니다. 현재 주행 차로를 감지하지 않습니다.
