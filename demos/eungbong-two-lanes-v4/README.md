# 응봉 두 진입 차로 종료 비교 v4

comparison.mp4는 전체 비교, highlights.mp4는 처음 10초를 생략한 비교다. 카카오 실제 음성을 보존했고 외부 하단 해설 자막은 없다.

도로는 두 진입 차로가 순서대로 끝나는 2 → 1 → 0 구조로 수정했다. 첫 종료는 재생 기준 약 335~390m, 두 번째는 약 588~628m의 거리뷰 관측 범위다. 두 앱에 같은 128개 GPS를 약 700m까지 재생했다. 차량은 도로 위에 표시하며 종방향 진행은 Pleos SDK, 횡방향 배치는 설명용 예시다. 현재 주행 차로를 감지하지 않는다. 사진 촬영월은 구간별 2026년 1·2·7·9월로 다르며 정밀 측량 자료가 아니다.

단위·기기 UI 103개, SDK 거리 콜백 131개, 동일 GPS/readback, 전체 영상 디코딩 검증 통과. 비교 대상은 모바일 카카오내비 4.52.1이며 Pleos용 카카오내비 실차 비교는 아니다.

이전 v3는 첫 차로 감소까지만 포함한 불완전한 도로 도식이므로 이번 v4로 대체한다. 이전 파일은 이력으로 보존했다.
