# 데모 영상 편집 방향

사용자 결정: 2026-11-15.

- 망원 짧은 진출 비교 영상은 `demos/mangwon-short-exit/`에 보존한다. 2026-11-15 최신 앱 화면 재촬영으로 갱신했다.
- 이후 데모에는 하단의 ‘이 시험의 관찰’, ‘이 기록에서는…’ 등 분석·해설 자막을 넣지 않는다. 앱의 실제 동작과 필요한 앱명/구간명으로 보여준다.
- 검증 근거와 범위는 별도 문서에 기록한다.
- 다음 주제는 ‘진입 차로가 앞까지 이어지다가 끝에서 본선과 합쳐지는 구조’다.
- 사용자 경험은 용산역→월곡역 방향의 내부순환로 진입 과정. 정확한 램프는 미특정.
- 기존 망원 C는 내부순환로에서 강변북로로 나오는 방향이므로 원래 사용자 경험과 같은 구간이라고 설명하지 않는다.
- 강변북로 일산방향→성산 연결로→내부순환로 방향의 기존 case-a는 후보였으나 차로 소멸 여부 미확정으로 이전 최종 판정에서 제외됐다. 후보와 확정 구간을 혼동하지 않는다.
