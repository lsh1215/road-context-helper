# 제품 우선 기준: Pleos에서 제공하지 않는 유용한 안내

2026-11-14 사용자 정정: 시연 종류를 늘리거나 기존 내비 안내를 다시 그리는 것이 목적이 아니다. Pleos에서 이미 제공하는 기능은 핵심 개발 대상에서 제외한다. 클러스터 스타일은 표현 방법이지 차별점이 아니다.

## 현재 판정

| 후보 | 판정 | 이유/남은 확인 |
|---|---|---|
| 단순 Y자 분기 | 핵심 데모 제외, 코드 제거 | 기본 방향 안내와 기능적 차이가 약하다. Pleos의 특정 버전/경로 동작을 관측했다는 의미는 아니다. |
| 단순 진출 전용 차로 안내 | 제품 차별성 미승인 | 기존 차로 안내와 겹칠 수 있다. 현재 그림은 비교용 프로토타입이다. |
| 진입 차로 끝의 본선 연결 설명 | 제품 차별성 미승인 | 기존 내비가 차로의 지속/소멸과 합류 지점을 얼마나 설명하는지 같은 구간 비교 필요. |
| 합류 직후 가까운 진출을 합류 전부터 설명 | 검증 우선 후보, 제품 차별성 미승인 | 기본 내비의 연속 안내/차로 안내가 이미 해결할 가능성을 배제할 수 없다. 다음 진출 노출 시점과 구조 설명의 차이를 확인해야 한다. |

## 후보 채택 기준

1. 비교 대상의 제품명·버전·날짜·경로를 남긴다. 연구용 에뮬레이터와 양산 Pleos 기능을 구분한다.
2. 같은 구간에서 기본 안내의 정보와 시점을 확인한다. 문서에서 찾지 못함/에뮬레이터 지도 고정은 기능 부재의 증거가 아니다.
3. 우리 앱이 추가하는 정보를 한 문장으로 설명한다. 같은 안내의 그림 변경만으로는 통과시키지 않는다.
4. 공개 SDK와 확보 가능한 도로 자료로 해당 추가 정보를 실제 산출할 수 있어야 한다. 현재 차로를 모르면 특정 차로에 있다고 전제하지 않는다.
5. 기본 내비만 사용할 때와 보조 안내가 있을 때 준비 시점/이해 차이를 비교한다. 검증 전 ‘Pleos에 없는 기능’으로 제출자료에 쓰지 않는다.
6. 별도 앱의 실시간 안내는 Pleos 경로 독점 정책 적용 범위부터 확인한다. 두 앱 표시 가능은 두 앱의 동시 경로 안내 허용을 의미하지 않는다.

## 확인한 공식 자료와 한계

- [Pleos Connect 공식 소개](https://www.hyundaimotorgroup.com/ko/news/hyundai-motor-group-redefines-in-vehicle-experience-with-pleos-connect-next-generation-infotainment-system), 2026-04-30: 실시간 안내·온라인 지도·모듈형 화면 설명. 이 소개만으로 개별 합류 안내의 유무는 판정할 수 없다.
- [Pleos 앱 마켓 발표](https://www.hyundaimotorgroup.com/ko/news/42dot-pleos-connect-app-market-new-apps), 2026-09-09: 카카오내비 입점과 차량 최적화 UI를 확인했다. 모바일판의 모든 기능이 차량판에도 동일하다고 추정하지 않는다. 비교 범위는 기본 내비에 더해 실제 설치 가능한 주요 내비도 포함한다.
- [Maps/Navigation 개발 가이드](https://document.pleos.ai/en/docs/pleos-only/vehicle-app-developer-guide/navigation-app-development-guide): 단일 활성 경로와 Inactive/Background 안내 제한. 기존 SDK 수신 성공은 동시 안내 정책 승인을 입증하지 않는다.

새 시나리오 개발은 이 기준의 비교 검증 전까지 확대하지 않는다. 이미 작성한 가상 예시는 UI 기술 검증이며 제품 차별성 검증이 아니다.

## 2026-11-14 모바일 비교 기록 반영

[합류 전 도로 맥락 비교 증거](../research/navigation-context-evidence-2026-11-14.md)에 망원 합류부의 두 목적지 경로, 카카오내비 4.52.1 가상 주행 녹화·음성·GPS와 관찰 결과를 보존했다. 기존 앱은 합류 전 왼쪽 출구·거리·녹색 차로 및 입체 진출 그림을 제공했다. 해당 실행에서는 진입 차로 소멸 위치와 합류 후 반대편 진출까지의 이동 부담을 묶은 설명을 관찰하지 못했다. 이는 지정한 모바일 시험의 결과이며 전체 기능 부재나 차량용 버전의 결과가 아니다.

제품 차별성 미승인 상태는 유지한다. 우리 앱의 기존 가까운 진출 도식은 왼쪽 진입→오른쪽 진출 가상 예시라, 실제 망원 오른쪽 진입→왼쪽 진출의 동일 구간 개선 시연으로 사용할 수 없다. 동일 실제 구간 적용, Pleos 기본 내비·차량용 카카오내비 비교 가능 범위 확인, 운전자 이해도 평가가 남아 있다. 후속 성공 기준과 발표에서 허용할 주장은 위 기록의 7–8절을 따른다.
