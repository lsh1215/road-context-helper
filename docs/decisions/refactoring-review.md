# 초행길 코드 구조 검토 · 2026-11-15

## 검토 범위

`app`, `core`, `integration`, `data`의 실행 코드와 관련 테스트를 검토했다. 현재 구조의 중심은 `integration`에서 읽은 차량 신호를 `RoadViewModel`이 받아 `core`·`data`의 판단 결과를 Compose 화면에 전달하는 방식이다. 도로 이미지용 Compose Canvas는 별도 파일에 모여 있다. 상태 판정과 UI가 전부 한 파일에 뒤섞인 구조는 아니지만, `RoadViewModel`은 권한·SDK 수명·데모·실제 안내·진단 로그를 함께 조율하므로 변경 시 회귀 범위가 크다.

## 이번에 수정한 문제

| 문제 | 변경 | 이유 |
|---|---|---|
| 도로 프로필 문자열과 자산 이름을 여러 화면에서 따로 해석 | `RoadReplayCase`에 지원 프로필과 자산 경로를 모음 | 새 사례를 추가할 때 어느 파일을 수정할지 분명해지고 오타에 따른 오동작을 줄임 |
| 알 수 없는 프로필이 양화 경로로 조용히 대체됨 | 지원하지 않는 프로필은 재생 세션 생성 단계에서 거부 | 잘못된 도로 구조를 실제 도로 안내처럼 보이지 않게 함 |
| 갤러리에 망원 여부·차로 끝 프로필의 중복 가변 상태 | 선택한 도로 프로필 하나에서 화면 상태를 도출 | 서로 모순된 선택 상태가 생기지 않게 함 |
| 응봉 외 망원 설명 분기에 도달 불가능한 조건, 응봉 거리 처리의 강제 null 해제 | 사례별 분기를 명시하고 안전한 값 비교로 변경 | 표시 규칙을 읽기 쉽게 하고 비정상 입력에 대비 |
| `RoadScreen`의 GPS 화면 조기 반환 뒤에 남아 있던 도달 불가능한 GPS 분기 | 해당 분기 제거 | 동일 동작을 중복 구현하지 않도록 함 |

## 검증과 한계

- 앱 APK·Android 테스트 APK 빌드, 앱·core·data JVM 테스트가 통과했다.
- 에뮬레이터에서 응봉, 망원, 갤러리, 일반 화면 총 27개 검사를 묶어 실행했으며 26개가 통과했다. 실패 1개는 `RoadScreenTest`가 Compose 화면 계층을 찾지 못한 실행 환경 오류였다. 해당 검사는 단독 재실행 통과, 같은 `RoadScreenTest` 클래스 15개도 별도 실행에서 전부 통과했다. 첫 묶음 실패는 삭제하거나 27개 모두 통과로 바꿔 기록하지 않는다.
- 카카오 비교 영상은 이전 빌드의 증거로 유지한다. 이번 리팩토링 후 GPS 전 구간을 재녹화하거나 실차에서 검증하지는 않았다.

## 후속 구조 개선

- `SdkLocationContext`가 SDK 위치 입력의 시계 검증, NaviHelper와 FusedLocation의 위치 맥락 확인, 경로 세대 번호를 관리한다. 리더가 재시작해도 경로 세대 번호가 뒤로 가지 않으며, 경로가 바뀌거나 연결이 끊기면 이전 내비 위치를 버린다.
- `RoadGuidancePresentation`이 실제 안내 결과를 화면 상태로 변환한다. `RoadViewModel`은 SDK 이벤트를 종류별 처리 함수에 전달하고 모드 전환 및 수명주기를 조율한다.
- 앱·Android 테스트 APK, 앱·core·data JVM 테스트, lint가 통과했다. 에뮬레이터에서 `RoadViewModelRegressionTest` 12개와 새 `SdkLocationContextTest` 1개가 모두 통과했다. 위치 맥락 검사는 가상 SDK 표본으로 수행했으며 실차 주행 검증을 뜻하지 않는다.

## 다음 구조 개선 우선순위

1. 진단 기록의 생성·저장 정책을 별도 객체로 옮기기. 현재 `RoadViewModel`이 이벤트별 JSON 필드를 구성하며, 기록 버전이나 저장 정책이 바뀌면 이 파일도 수정해야 한다.
2. 새 도로 사례를 추가할 때 코드뿐 아니라 자료의 출처·검수 상태·종료 구간을 함께 등록하는 명시적 계약. 지금의 프로필 열거형은 지원 사례 식별에는 충분하지만 전국 도로 자동 분류 체계는 아니다.
3. 큰 Canvas 파일은 현재 도로 도식 전용 함수로 분리되어 있다. 파일 크기만 줄이려고 함수를 옮기기보다는, 새로운 사례가 실제로 중복된 도형 연산을 요구할 때 공유 기하를 추출한다.
